# Legacy cuisine data (v0.5 rules)

Mexico, Japan, USA, Spain and France as they were in v0.5, before the
Overcooked-style cooking rules of v0.6 (see docs/V06_DESIGN.md). The game
does not load anything in this folder. These files are kept as the starting
point for converting the five cuisines to the new rules, after which this
folder is deleted. `make_v05_cuisines.py` is the old content script and only
works with the old format.
